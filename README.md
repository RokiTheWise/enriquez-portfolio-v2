# Enriquez Portfolio V2

Personal portfolio for Dexter Jethro Enriquez — a single-page site built with Next.js 16, React 19, and a heavy emphasis on motion and 3D.

## Stack

| Layer | Tech |
|---|---|
| Framework | Next.js 16 (App Router) |
| UI | React 19, Tailwind CSS v4, shadcn/ui |
| Animation | Framer Motion, GSAP |
| 3D | React Three Fiber, Three.js, OGL |
| Smooth scroll | Lenis |
| Language | TypeScript |

## Sections

- **Hero** — WebGL canvas with particle effects and a mouse-reactive portrait quad (R3F)
- **About** — Bento-grid layout with personal background
- **Tech Stack** — Logo loop marquee
- **Featured Projects** — Horizontal scroll gallery (CSS sticky + Framer Motion), featuring:
  - [Aklatang Galera](https://aklatang-galera.djenriquez.dev) — bilingual civic portal for Puerto Galera
  - [LogiSketch](https://logisketch.djenriquez.dev) — Boolean logic synthesis tool with Quine-McCluskey minimization
  - [ACE & Company](https://aceandco.org) — corporate site for an accounting firm
- **Beyond the Code** — Personal interests and highlights
- **Contact** — Links and contact form

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev      # development server (Turbopack)
npm run build    # production build
npm run start    # production server
npm run lint     # ESLint
```
